# Temporal reader implementation scope

Own temporal reader fast paths in RuntimeGenerator.cs and focused regression tests.
Do not change the writer API, group membership strategy or reader projection architecture.

The prototype is versioned at benchmarks/experiments/temporal-reader/fast-path.patch.
Use it as evidence/reference, not as an instruction to apply a patch blindly. Its contract
probe is a useful starting point; convert representative cases into permanent tests that
fit the repository's Roslyn compilation-driver pattern.

Preserve the original fallback, values, success/failure and DateTime Kind. Cover invalid
digits/separators, truncation, year/month/day boundaries, leap/century years and fractions.
Validate the existing consumer floor, including the compatibility project. Do not run long
benchmarks here: the integrator will run controlled comparisons after review.
